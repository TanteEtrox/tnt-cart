# TNT Cart (Fabric, Minecraft 26.2, nur Client)

Taste Y (aenderbar unter Steuerung > TNT Cart): Flame-Bogen spannen, schiessen, Schiene und TNT-Lore setzen.
Hotbar: Bogen mit Flame, beliebige Schiene, TNT-Lore. Auf die Oberseite eines Blocks (max. 4 Bloecke) schauen.

## Jar bauen (GitHub)
1. Neues GitHub-Repo, diesen Ordnerinhalt hochladen (inkl. .github/workflows/build.yml).
2. Tab "Actions" > letzter Lauf > Artifacts > "Artifacts" herunterladen.
3. Die Datei tntcart-1.0.0.jar (nicht -sources) in den mods-Ordner legen. Fabric API wird gebraucht.
